# Primary analysis release status

Status: selected independently developed reproducibility scripts.

Contains 11 verified Python scripts copied
without modification from the independent
HIV vaccine BCR research project.

The Figure 1A reconstruction requires
frozen intermediate data, including the
15-participant profile table 198.

The code is not yet demonstrated to execute
end to end in a clean environment using
only the original public G002 release.

Some historical scripts use workspace-specific
paths and require a documented input directory.

The original third-party G002 dataset,
participant-level tables and sequences are
not included.

The independently developed source code is
owned by Kazi Tanzina Begum.

This selected-code package is not a complete
end-to-end computational reproduction environment.

The original G002 data are not redistributed.
See the repository provenance and licensing notes.
